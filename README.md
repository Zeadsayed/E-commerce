# Market — E-commerce Storefront

An Angular e-commerce storefront that lists products, lets shoppers filter by category, search, and add items to a cart, backed by the public Fake Store API.

Live demo: https://zeadsayed.github.io/E-commerce/

## Features

- Product catalog with images, descriptions, and prices
- Category filtering and search
- Shopping cart with live item count
- Data fetched from the Fake Store API

## Tech stack

- Angular
- TypeScript
- RxJS
- HTML/CSS

## Getting started

```bash
git clone https://github.com/Zeadsayed/E-commerce.git
cd E-commerce
npm install
ng serve
```

Then open http://localhost:4200 in your browser.
